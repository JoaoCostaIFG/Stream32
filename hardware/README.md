# Printable hardware

3D-printable enclosures and stands for Stream32 boards. Each design ships as
a `.step` file for slicing or CAD import and a `.f3d` Fusion archive for
editing. Print settings are up to you; every file was designed for ordinary
FDM printing.

| File | Fits | Notes |
| --- | --- | --- |
| `Stream32-ElecrowPanel10_1-case-and-stand.step` / `.f3d` | Elecrow CrowPanel Advanced 10.1" | Case plus an optional desk stand |
| `Stream32-ElecrowPanel10_1.3mf` | Elecrow CrowPanel Advanced 10.1" | Printable stand only, predates the full case |
| `Stream32-WaveshareTouchLCD4-case.step` / `.f3d` | Waveshare ESP32-S3-Touch-LCD-4 Rev 3.0 and 4.0 | One case fits both revisions |

The CrowPanel case and stand need 8x M3x5x4 heat-set inserts and 8x M3x10
screws; only 4 screws are needed if you skip the stand.
